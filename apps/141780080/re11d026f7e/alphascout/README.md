# AlphaScout

AI-powered autonomous market intelligence agent for Base prediction market traders.

## Features

* Live prediction market scanning
* AI odds analysis
* High conviction trade detection
* Telegram trading assistant
* Autonomous market monitoring
* Base chain connectivity
* Aomi-compatible execution architecture

## Stack

* Rust
* Axum
* Telegram Bot API
* Aomi SDK
* Base
* Docker

## Commands

* scan market
* analyze odds
* high conviction

## Run Locally

```bash
cargo run -p alphascout-agent
```

## Telegram Bot

```bash
node index.js
```

## Docker

```bash
docker build -t alphascout .
docker run -p 8080:8080 alphascout
```

## Vision

AlphaScout turns natural language into actionable crypto market intelligence and autonomous execution on Base using Aomi infrastructure.
